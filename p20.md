# контекст:
Изучи документацию к проекту - README.md в корне решения. Если необходимо исследуй файлы.
Есть два режима работы на странице "маршруты обучения". Первый режим-это без базы знаний, то есть без использования rag.
 2-й режим - Мы загружаем базу знаний из PDF файлов, используя её в том числе для генерации тестов.
 Список тем подтягивается из файла backend/themeCollection.json
# цель:
- Нужно дать возможность администратору через админку "Управление темами" для тем, которые не используют rag создавать список разделов
вручную.
- список разделов для данной темы сохранять в файле themeCollection.json для этого расширь этот json
- если для данной темы назначается источник из rag, то разделы должны использоваться, те которые нарезаны при обработке pdf, т.е. rag в приоритете
- для того чтобы пользователь видел список наших разделов, которые добавлены вручную, на странице "Маршрут обучения" под чекбоксом "Привяка к источнику (RAG)" добавь ещё чекбокс 
"Рекомендуемые разделы", после нажатия на который отображается комбобокс со списком разделов. Справа от этого комбобокса должна быть кнопка "Добавить в запрос", 
нажав на которую в чат добавляется фраза "Расскажи подробнее про раздел: " + название выбранного раздела
- если тема привязана к источнику и выбран чекбокс "Привязка к источнику (RAG)", то список разделов, добавленных вручную, а также чекбокс и кнопка, 
относящиеся к этому списку не отображаются
