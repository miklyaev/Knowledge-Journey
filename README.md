# Knowledge Journey 🚀

**Knowledge Journey** — это инновационная образовательная платформа, которая использует искусственный интеллект для создания персонализированных маршрутов обучения в реальном времени. Приложение превращает изучение любой темы в интерактивное приключение с проверкой знаний через разнообразные игровые механики.

## 🌟 Ключевые возможности

- **Генерация контента на лету**: Введите любую тему, и ИИ (через OpenAI/GigaChat) составит для вас структурированный план обучения и набор проверочных заданий.
- **Разнообразие игровых механик**:
  - Одиночный и множественный выбор.
  - Заполнение пропусков.
  - Сопоставление пар.
  - Упорядочивание шагов.
  - Свободные ответы с проверкой ИИ.
  - Истинное/Ложное.
- **Система мотивации**: Начисление баллов за правильные ответы и учет времени прохождения.
- **Журнал успехов**: Личный кабинет пользователя, где хранится история всех пройденных маршрутов, набранные баллы и детальная статистика.
- **Безопасность**: Система аутентификации, защищающая личные отчеты пользователей. Просмотр чужих достижений возможен только при наличии пароля.
- **Интерфейс в стиле GNOME**: Уникальный визуальный стиль, имитирующий современную рабочую среду Linux.

## 🛠 Технологический стек

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide Icons.
- **Backend**: Node.js, Express.
- **AI**: Интеграция с LLM (OpenAI API / GigaChat) для генерации заданий.
- **State Management**: React Context API для авторизации.

## 🚀 Быстрый старт

### Предварительные требования
- Node.js (версия 18 или выше)
- npm или yarn

### Настройка окружения

1. **Backend**:
   Перейдите в папку `backend` и создайте там файл `.env`:
   cp .env.local .env 

# Установите константы вашими данными
# для Гигачат
GIGACHAT_CLIENT_ID=YOUR_GIGACHAT_CLIENT_ID
GIGACHAT_CLIENT_SECRET=YOUR_GIGACHAT_CLIENT_SECRET
GIGACHAT_API_KEY=YOUR_GIGACHAT_API_KEY

# И\ИЛИ для Yandex
YANDEXGPT_API_KEY=YOUR_YANDEXGPT_API_KEY
YANDEXGPT_FOLDER_ID=YOUR_YANDEXGPT_FOLDER_ID

#  для базы данных данные не нужно указывать, этот функционал пока не реализован


### Установка зависимостей

```bash
# Установка зависимостей для фронтенда
npm install

# Установка зависимостей для бэкенда
cd backend
npm install
cd ..
```

### Запуск приложения

Для полноценной работы необходимо запустить оба сервера:

1. **Запуск бэкенда** (хранение отчетов и аутентификация):
   ```bash
   cd backend
   node server.js
   ```

2. **Запуск фронтенда**:
   ```bash
   # В новом окне терминала (из корня проекта)
   npm run dev
   ```

Приложение будет доступно по адресу: [http://localhost:3030]

## 📝 Как пользоваться

1. **Авторизуйтесь**: Введите свой никнейм и пароль (если аккаунт новый, он будет создан автоматически).
2. **Создайте маршрут**: На главной странице или в разделе "Маршрут обучения" введите тему, которую хотите изучить (например, "Основы игры в нарды" или "Квантовая физика").
3. **Проходите тесты**: ИИ сгенерирует этапы. Проходите их, следя за таймером.
4. **Сохраняйте результат**: В конце вы получите финальный отчет, который можно сохранить в свой "Журнал успехов".
5. **Анализируйте**: Перейдите в "Журнал успехов", чтобы увидеть свой прогресс и общее количество набранных баллов.
