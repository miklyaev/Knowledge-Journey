# Knowledge Journey 🚀

**Knowledge Journey** — интерактивная образовательная платформа с генеративным ИИ, которая создаёт персонализированные маршруты обучения в реальном времени. Изучение любой темы превращается в приключение с проверкой знаний через игровые механики и подкрепляется контекстом из собственных PDF-документов (RAG).

> 🌐 **Продакшен**: [http://ai-nvkz.ru](http://ai-nvkz.ru)
> 📦 **Репозиторий**: [github.com/miklyaev/Knowledge-Journey](https://github.com/miklyaev/Knowledge-Journey)

## 🌟 Ключевые возможности

- **AI-генерация контента**: Введите тему — GigaChat или YandexGPT составляет структурированный план обучения с набором проверочных заданий.
- **7 типов заданий**: true‑false, single‑choice, multiple‑choice, fill‑the‑blank, order‑steps, match‑pairs, free‑response (с оценкой ИИ).
- **RAG-база знаний**: Загружайте PDF → автоматический парсинг, чанкинг и векторизация в ChromaDB → контекст подтягивается в промпт при ответах.
  - Очистка PDF: удаление лишних страниц, извлечение разделов по регулярному выражению.
  - Тестирование regex перед индексацией.
- **Система мотивации**: Баллы за правильные ответы, взвешенные по сложности задания (от 2 до 10 баллов).
- **Журнал успехов**: История всех маршрутов, баллы, детальная статистика по каждому заданию.
- **Аутентификация**: Регистрация/вход по никнейму + пароль (bcrypt).
- **Админ-панель**: Привязка PDF к темам, управление источниками знаний, очистка темы.
- **Интерфейс в стиле GNOME**: Визуальный стиль, имитирующий рабочую среду Linux (Ubuntu).

## 🛠 Технологический стек

| Компонент | Технологии |
|-----------|------------|
| **Frontend** | Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion, Lucide Icons |
| **Backend** | Node.js 20, Express 4 (ESM), multer, bcryptjs |

| **Deploy** | Docker Compose, Nginx (VDS / ai-nvkz.ru) |

## 🚀 Быстрый старт

### Предварительные требования
- Node.js (версия 18 или выше)
- npm или yarn
- MySQL 8.0 (обязательно)

### Настройка окружения

1. **Backend**:
   Перейдите в папку `backend` и создайте там файл `.env`:
   cp .env.local .env 

### Инициализируйте константы вашими данными
### для Гигачат
- GIGACHAT_CLIENT_ID=YOUR_GIGACHAT_CLIENT_ID
- GIGACHAT_CLIENT_SECRET=YOUR_GIGACHAT_CLIENT_SECRET
- GIGACHAT_API_KEY=YOUR_GIGACHAT_API_KEY

### И\ИЛИ для Yandex
- YANDEXGPT_API_KEY=YOUR_YANDEXGPT_API_KEY
- YANDEXGPT_FOLDER_ID=YOUR_YANDEXGPT_FOLDER_ID

### Данные для базы данных (ОБЯЗАТЕЛЬНО)
- DB_HOST=localhost
- DB_PORT=3306
- DB_NAME=knowledge_journey
- DB_USER=your_user
- DB_PASSWORD=your_password

### Установка зависимостей

```bash
# Установка зависимостей для фронтенда
npm install

# Установка зависимостей для бэкенда
cd backend
npm install
cd ..
```

### Запуск приложения

Для полноценной работы необходимо запустить оба сервера:

1. **Запуск бэкенда** (хранение отчетов и аутентификация):
   ```bash
   cd backend
   node server.js
   ```

2. **Запуск фронтенда**:
   ```bash
   # В новом окне терминала (из корня проекта)
   npm run dev
   ```

Приложение будет доступно по адресу: [http://localhost:3030]

## 📝 Как пользоваться

1. **Авторизуйтесь**: Введите свой никнейм и пароль (если аккаунт новый, он будет создан автоматически).
2. **Создайте маршрут**: На главной странице или в разделе "Маршрут обучения" введите тему, которую хотите изучить (например, "Основы игры в нарды" или "Квантовая физика").
3. **Проходите тесты**: ИИ сгенерирует этапы. Проходите их, следя за таймером.
4. **Сохраняйте результат**: В конце вы получите финальный отчет, который можно сохранить в свой "Журнал успехов".
5. **Анализируйте**: Перейдите в "Журнал успехов", чтобы увидеть свой прогресс и общее количество набранных баллов.
