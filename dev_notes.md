# Dev Notes

## 2026-07-06 — Исправление подключения к API на VDS

- **docker-compose.yml**: Синхронизированы порты бэкенда (`3031:3031`) и обновлена переменная `NEXT_PUBLIC_API_BASE_URL` на внутренний адрес Docker (`http://backend:3031`).
- **Сетевые настройки**: Реализовано проксирование API через Next.js роуты. Теперь фронтенд обращается к `/api/...` на том же домене, что решает проблемы Mixed Content (HTTP/HTTPS) и CORS на VDS. Добавлены прокси-роуты для `/api/themes` и `/api/ai/evaluate`.
Краткий журнал ключевых изменений проекта.

### 2026-07-01 — Динамическая загрузка тем обучения

**Область:** Frontend, Backend

**Что изменилось:**
- Создан конфигурационный файл `themeCollection.json` на бэкенде для хранения тем обучения.
