# Dev Notes

## 2026-08-13 — Исправление оценки свободного ответа

**Область:** Backend, Frontend

**Что изменилось:**
- Исправлен разбор ответа ИИ для `POST /api/ai/evaluate`: прежнее регулярное выражение искало экранированные символы вместо JSON-объекта, поэтому любая корректная оценка завершалась fallback-ответом на 2 балла.
- Разбор вынесен в `parseEvaluationResponse` с проверкой диапазона `score` от 0 до 10 и непустого `feedback`.
- Поддержаны как чистый JSON, так и JSON внутри Markdown-блока или сопроводительного текста.
- Добавлены изолированные unit-тесты успешных и некорректных ответов ИИ, а также backend-команда `npm test`.
- `TimerFreeResponse` продолжает явно обрабатывать fallback-контракт API с полем `error`.

**Затронутые пути:**
- `backend/server.js`
- `backend/evaluationParser.js`
- `backend/evaluationParser.test.js`
- `backend/package.json`
- `src/components/TimerFreeResponse.tsx`

**Зачем / контекст:**
Корректный ответ ИИ ранее не мог пройти парсинг и во всех случаях отображалось сообщение «Ошибка при связи с ИИ». Новый парсер устраняет первопричину и проверяет контракт до передачи результата компоненту.

## 2026-08-07 — Реализация "Рекомендуемые разделы" для тем без RAG

**Область:** Frontend, Backend

**Что изменилось:**
- **`backend/themeCollection.json`**: Расширена структура каждой темы новым полем `sections: []` (массив строк с названиями разделов).
- **`backend/server.js`**: 
  - Эндпоинты `POST /api/themes/add`, `PUT /api/themes/:id`, `DELETE /api/themes/:id` теперь сохраняют и удаляют `sections`.
- **`src/app/knowledgeJourney/page.tsx`**: 
  - Добавлены состояния для управления рекомендуемыми разделами: `recommendedSections`, `isRecommendedSectionsEnabled`, `selectedRecommendedSection`, `pendingRecommendedSectionTitle`.
  - Добавлен useEffect для загрузки `sections` из выбранной темы.
  - Добавлен UI чекбокс "Рекомендуемые разделы" (видим только если RAG отключен).
  - При включении чекбокса показывается комбобокс со списком разделов и кнопка "Добавить в запрос".
  - При нажатии кнопки устанавливается `pendingRecommendedSectionTitle` с фразой "Расскажи подробнее про раздел: [название]".
- **`src/components/AIAssistant.tsx`**: 
  - Добавлены props `pendingRecommendedSectionTitle` и `onRecommendedSectionTitleHandled`.
  - Добавлен useEffect для обработки рекомендуемых разделов (аналогично RAG разделам).
- **`src/components/ThemesModal.tsx`**: 
  - Добавлена секция "Рекомендуемые разделы (макс. 50)" в форме редактирования/добавления темы.
  - Поле ввода для добавления нового раздела + кнопка "Добавить".
  - Список добавленных разделов с кнопками удаления.
  - Валидация: проверка на пустоту, дубликаты, лимит 50 разделов.

**Затронутые пути:**
- `backend/themeCollection.json`
- `backend/server.js`
- `src/app/knowledgeJourney/page.tsx`
- `src/components/AIAssistant.tsx`
- `src/components/ThemesModal.tsx`

**Зачем / контекст:**
Для тем обучения, которые не имеют привязанного PDF-источника (и, следовательно, не используют RAG), система позволяет администратору определить рекомендуемые разделы. Пользователи видят эти разделы на странице "Маршруты обучения" под чекбоксом "Привязка к источнику (RAG)" и могут выбрать раздел для добавления в чат. При нажатии "Добавить в запрос" в чат добавляется фраза "Расскажи подробнее про раздел: [название раздела]".

**Логика приоритета:**
- Если RAG включен и есть разделы из PDF → используются RAG разделы, чекбокс "Рекомендуемые разделы" скрыт.
- Если RAG отключен → видим чекбокс "Рекомендуемые разделы" с ручными разделами.

**Фраза в чате:**
Идентична RAG: "Расскажи подробнее про раздел: [название раздела]"
