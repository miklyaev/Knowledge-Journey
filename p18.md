# контекст:
Изучи документацию к проекту - README.md в корне решения. Если необходимо исследуй файлы.
Последняя задумка была в том, чтобы использовать два режима работы на странице "маршруты обучения". Первый режим-это без базы знаний, то есть без использования rag.
 2-й режим - Мы загружаем базу знаний из PDF файлов, используя её в том числе для генерации тестов.
 Перед тем как использовать pdf-файлы мы их можем обработать: убрать страницы, которые нам не нужны в rag, разбить по разделам с помощью регулярного выражения.
 Но здесь тоже есть ограничения, если например разделы не нумеруются, а просто отделяются заголовком, который выделен шрифтом и расположен по центру страницы
# цель:
- На странице настройка привязки к источнику добавить возможность выделять разделы не только по регулярному выражению, но используя алгоритм из скрипта
backend/rag/extractChunks.js
- добавить возможность выбора режима, например с помощью radiobutton. Первое положение "Регулярное выражение для разделов
" при этом функционал не меняется, второе положение "Если разделы по центру без нумерации" - используем вышеописанный алгоритм.
- кнопка "тест" должна работать в обоих режимах.
